# Gym Tracker

A minimal workout tracking web app built with React + TypeScript.

## Features

- Create and edit workout routines
- Add exercises with sets, reps, and weights
- Active workout mode with live tracking
- Editable sets during workout
- Persistent data using localStorage

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Future ideas

- Workout history
- Progress tracking
- PWA support
